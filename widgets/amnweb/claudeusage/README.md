# Claude Usage

Your Claude plan limits from Claude Code, with reset times, Claude status and the tokens Claude Code used by day, week, month and model

```
yasbc addons install amnweb.claudeusage
```

Your Claude plan limits on the bar: the 5-hour and 7-day use, and weekly model limits, with when each resets. The popup adds Claude's status and the tokens Claude Code used per session, day, week, month and year, by model.

**Needs** Claude Code signed in on this PC. It reads Claude Code's sign-in from `~/.claude/.credentials.json` and sends it only to Anthropic, and scans Claude Code's logs for tokens.
