# Orbit

A power menu whose actions burst from the bar into a ring of orbs. Hold one to run it, and the screen folds away like an old CRT

```
yasbc addons install amnweb.orbit
```

A power menu that shows off Qt Quick. Your actions burst out of the bar into a ring of glowing orbs around your picture. **Hold** an orb to run it, so a stray click never shuts you down. The orbs then collapse, a shockwave rings out and the screen folds away like an old CRT.

Add `amnweb.orbit` to a bar. Esc or a click outside closes it, and the arrow keys with Enter work too. `actions`, `holdDuration`, `particles` and the other options are at the top of `Orbit.qml`.
